# Pragya Sharma — React Portfolio

A premium, spacious, interactive portfolio built with React 18 and Lucide icons.

## Included
- Dark/light theme
- Responsive navigation
- Hero with photo placeholder
- Interactive skill categories
- Experience timeline
- FinTech + Healthcare project architecture modals
- Engineering process section
- Animated reveal-on-scroll
- Copy-email interaction
- Contact form UI
- GitHub/LinkedIn/LeetCode links

## Add your photo
Put your professional photo at:

`assets/pragya.jpg`

The hero will use it automatically.

## Add your resume
Put your PDF at:

`assets/Pragya-Sharma-Resume.pdf`

## GitHub Pages
This version intentionally uses React through CDN so you can upload it directly to the `pragya0106.github.io` repository without running npm locally.

After upload, enable:
Settings → Pages → Deploy from branch → main → / (root)
