# Pragya Sharma — Interactive Developer Portfolio

A GitHub Pages-friendly portfolio for Pragya Sharma, Software Engineer.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a repository named `pragya0106.github.io`.
2. Copy all files from this folder into the repository.
3. Add your current PDF resume at:
   `resume/PragyaSharma_SoftwareEngineer.pdf`
4. Push to GitHub.
5. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
6. Your portfolio will be available at:
   `https://pragya0106.github.io/`

## Important
The two featured projects are explicitly labelled as self-directed portfolio projects. Replace the GitHub links in `index.html` with the actual project repository URLs after you build/push those repositories.
